# Opportunity Engine V1 평가 모델 설계 및 가설 (Hypothesis) 문서

> **문서 버전**: V1.0 (Hypothesis Baseline)  
> **작성 일시**: 2026-08-19  
> **상태**: **[가설(HYPOTHESIS) 단계]** — 실제 시장 데이터 30~50개 축적 후 임계값 재검증 예정  
> **적용 원칙**: 임의의 100점짜리 가중치 산식 금지, 각 차원별 시그널 기반 판정 및 데이터 부재 시 '판정 보류(HOLD)' 원칙 준수

---

## 1. 개요 및 사업적 목표

단순히 "검색량이 많은 키워드"가 아니라, **"자체 기획/동대문·도매 소싱/자체 제작 역량을 갖춘 우정어패럴이 신규 진입하여 마진을 남기고 순위권에 안착할 수 있는가?"**를 실데이터(SearchAd + DataLab + SerpApi + AC) 기반으로 평가한다.

---

## 2. 7대 평가 차원 및 초기 가설 임계값 (Hypothesis Thresholds)

| 평가 차원 | 실데이터 원천 | 가설 기준 및 임계값 (Hypothesis) | 평가 방향 (Signal) |
| :--- | :--- | :--- | :--- |
| **1. 수요 (Demand)** | Naver SearchAd 월간 총 검색량 | • **과열(Too High)**: 100,000회 이상<br>• **적정 유효구간(Optimal)**: 3,000 ~ 50,000회<br>• **니치(Niche)**: 1,000 ~ 3,000회<br>• **수요 부족(Dead)**: 1,000회 미만 | • 과열: 대기업/빅브랜드 전장이므로 롱테일 우회 필요<br>• 적정: 소호 셀러 침투 최적 구간<br>• 부족: 진입 제외(PASS) |
| **2. 트렌드 & 채널** | Naver DataLab 쇼핑 트렌드 & 모바일 비중 | • **트렌드**: RISING(급상승) / STABLE(안정) / DECLINING(하강)<br>• **모바일 비중**: 70% 이상 권장 | • 급상승: 선점 기회 (가점)<br>• 하강: 재고 리스크 경고<br>• 모바일 70%+: 비주얼 상세페이지 전환율 유리 |
| **3. 가격 여력 (Margin Pool)** | SerpApi 상위 상품 중앙가 (Median Price) | • **출혈 저가**: 중앙가 < 12,000원<br>• **스위트 스팟**: 18,000원 ~ 45,000원<br>• **고가 프리미엄**: 70,000원 이상 | • 출혈 저가: 사입/배송/수수료 제하면 마진 파괴 (PASS)<br>• 스위트 스팟: 마진 35%~50% (8,000~15,000원) 확보 가능<br>• 고가: 브랜드 신뢰도 없이 진입 시 전환율 저조 |
| **4. 리뷰 장벽** | SerpApi 상위 상품 평균/중앙 리뷰 수 | • **진입 불가**: 상위 평균 리뷰 > 2,000개<br>• **진입 가능**: 상위 평균 리뷰 50 ~ 500개<br>• **데이터 누락**: UNKNOWN (점수 부여 금지) | • 고착화 시장 vs 초기 침투 가능 시장 구분<br>• 리뷰수 미제공 시 임의 감점 없이 판정 보류 |
| **5. 광고 경쟁도** | SerpApi 상위 노출 중 `isAd: true` 비율 | • **과포화(Ad Saturated)**: 광고 70% 이상<br>• **오가닉 기회(Organic Open)**: 자연노출 50% 이상 | • 광고 과포화: CPC 출혈 경쟁 위험<br>• 자연노출 확보: SEO 및 상세페이지로 오가닉 상위 노출 가능 |
| **6. 브랜드 집중도** | SerpApi 판매처(mallName) 및 상품명 분석 | • **브랜드 독점(Brand Monopoly)**: 공식몰/대기업 50%+<br>• **소호 중심(Soho Friendly)**: 스마트스토어/소호몰 50%+ | • 대기업 브랜드 독점 시장 제외<br>• 소호 중심 시장은 우정의 기획력으로 승부 가능 |
| **7. 데이터 무결성** | 수집 엔진 전반 | • 필수 데이터 누락 또는 API 오류 시 | • **임의 점수 산출 금지 $\rightarrow$ 반드시 '판정 보류(HOLD)'** |

## 3. 최종 의사결정 매트릭스 (Verdict Rules)

```
[데이터 신뢰도 체크]
  ├─ 필수 지표 중 UNKNOWN 존재? ──> ❓ HOLD (데이터 불충분 / 사유 명시)
  └─ 데이터 완전 수집 완료
        │
        ├─ 검색량 < 1,000 OR 중앙가 < 12,000원 OR 대기업 독점? ──> ⛔ PASS (진입 제외)
        ├─ 유효 수요(3천~5만) AND 중앙가 1.8만+ AND 소호 점유 50%+? ──> 🚀 GO (진입 추천)
        └─ 그 외 (트렌드 하강, 광고 비중 과다 등 검토 필요 시) ──> ⏳ WAIT (조건부 대기 / 모니터링)
```

## 4. 향후 검증 로드맵

1. **Step 1 (다음 작업)**: 10개 실전 테스트 키워드로 본 규칙 시뮬레이션 실행 (지나치게 엄격/느슨한 기준 식별)
2. **Step 2**: 실전 30~50개 키워드 데이터 축적 후 임계값 통계 분석 및 정밀 튜닝
3. **Step 3**: 검증 완료된 규칙을 Opportunity Engine V1 코드로 최종 구현
